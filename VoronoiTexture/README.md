# Voronoi Texture for Unity URP

Процедурная текстура диаграммы Вороного реального времени для Unity 2022.3+ и Unity 6 (Universal Render Pipeline). Поддерживает вычисление расстояний F1/F2, точные контуры ячеек, различные метрики, процедурную анимацию и запекание. Полностью совместима с SRP Batcher.

## Возможности

- **Режимы генерации:**
  - `F1` — расстояние до ближайшего центра.
  - `F2` — расстояние до второго ближайшего центра.
  - `F2MinusF1` — разность расстояний ($F_2 - F_1$).
  - `Edges` — контуры ячеек фиксированной ширины и случайная заливка цветом.
- **Метрики расстояния:** Euclidean (евклидова), Manhattan (манхэттенская), Chebyshev (чебышёвская).
- **Анимация:** процедурное смещение точек во времени без разрывов сетки.
- **Запекание:** компонент `VoronoiBaker` для вывода в `RenderTexture` и сохранения в PNG.

## Установка за 3 шага

1. Скопируйте папку `VoronoiTexture` в директорию `Assets/` вашего проекта.
2. Создайте новый Material (`Assets > Create > Material`) и укажите шейдер `Custom/VoronoiURP`.
3. Назначьте созданный Material на меш (например, стандартный `Quad` или `Plane`).

## Параметры шейдера

| Параметр | Свойство в коде | Тип / Диапазон | По умолчанию | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **Scale** | `_Scale` | Float | `8.0` | Масштаб сетки ячеек Вороного. |
| **Jitter** | `_Jitter` | Range(0, 1) | `1.0` | Хаотичность смещения центров (0 — регулярная сетка, 1 — максимум). |
| **Seed** | `_Seed` | Float | `0.0` | Сид генератора псевдослучайных чисел. |
| **Anim Speed** | `_AnimSpeed` | Float | `0.5` | Скорость процедурного движения центров ячеек. |
| **Mode** | `_Mode` | KeywordEnum | `Edges` | Режим: `F1`, `F2`, `F2MinusF1`, `Edges`. |
| **Metric** | `_Metric` | Enum | `Euclidean (0)` | Метрика расстояния: `Euclidean` (0), `Manhattan` (1), `Chebyshev` (2). |
| **Edge Width** | `_EdgeWidth` | Range(0.001, 0.5) | `0.05` | Толщина границ ячеек (только для режима `Edges`). |
| **Contrast** | `_Contrast` | Range(0.1, 4.0) | `1.0` | Контрастность итогового значения (`pow(v, Contrast)`). |
| **Color A** | `_ColorA` | Color | `(0.05, 0.05, 0.08, 1)` | Цвет фона / начальный цвет градиента. |
| **Color B** | `_ColorB` | Color | `(0.9, 0.6, 0.3, 1)` | Цвет ячеек / конечный цвет градиента. |
| **Edge Color** | `_EdgeColor` | Color | `(1, 1, 1, 1)` | Цвет контуров границ в режиме `Edges`. |

## Использование VoronoiBaker

1. Добавьте компонент `VoronoiBaker` на любой GameObject сцены.
2. Назначьте материал с шейдером `Custom/VoronoiURP` в поле **Material**.
3. *(Опционально)* Укажите **Target Renderer**, чтобы каждый кадр передавать сформированный `RenderTexture` в материал другого объекта.
4. Нажмите правой кнопкой мыши на заголовок компонента и выберите пункт контекстного меню **Save PNG** — файл запишется в папку `Assets/VoronoiTexture/Baked/`.

## Почему режим Edges использует дистанцию Иниго Килеза, а не F2-F1

- **Проблема $F_2 - F_1$:** значение разности расстояний до двух ближайших центров зависит от взаимного расположения и удаленности точек. Вблизи узких граней линии истончаются, а на стыках трех и более ячеек размываются и неестественно утолщаются.
- **Решение Иниго Килеза (Inigo Quilez):** алгоритм сначала находит ближайшую ячейку, а на втором проходе проецирует вектор до точки на срединный перпендикуляр к каждому соседу. Это дает точное евклидово расстояние от пикселя до ребра границы, гарантируя строго одинаковую толщину линий (`Edge Width`) по всей текстуре независимо от геометрии ячеек.
